                                      🐋 Dockerizando tu Inventario en AWS ☁️

¡Hola! Este proyecto es una guía y una demostración práctica de cómo tomar una aplicación web (compuesta por un frontend y un backend), "dockerizarla" y desplegarla en la nube de AWS usando los servicios EC2 y ECR.

El objetivo es pasar de un entorno de desarrollo local a un servidor en la nube al que se pueda acceder desde cualquier lugar del mundo. ¡Acompáñame en esta aventura!

⚙️ Tecnologías Utilizadas
Docker & Docker Compose: Para crear contenedores de nuestra aplicación y orquestarlos.

AWS (Amazon Web Services):

EC2 (Elastic Compute Cloud): Nuestro servidor virtual (nuestra "computadora") en la nube donde correrán los contenedores.

ECR (Elastic Container Registry): Nuestro garaje privado en la nube para almacenar las imágenes de Docker.

IAM (Identity and Access Management): Para gestionar los permisos de forma segura entre los servicios de AWS.

AWS CLI: Para interactuar con nuestra cuenta de AWS desde la terminal.
